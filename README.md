# Structural Studio — Local Engineering Workspace (v0.18.0)

**برنامج بحث وتطوير هندسي محلي** يختبر مسارًا من قراءة مخططات DXF المعمارية إلى بناء نموذج إنشائي مرشح ومراجعته، مع وكيل AI محلي يستخدم أدوات هندسية.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. فك ضغط المشروع وشغّل `setup_windows.bat` مع اتصال الإنترنت لتثبيت المتطلبات.
3. شغّل `run_app.bat` لفتح الواجهة المحلية.
4. لتجربة الوكيل، ثبّت [Ollama](https://ollama.com/download/windows)، ثم شغّل `SETUP_LOCAL_AI_MODEL.bat`. داخل الواجهة اختبر **ردًا حيًا واستدعاء أداة فعليًا** قبل استخدام الوكيل.
5. شغّل `RUN_FULL_TEST_SUITE.bat` لتشغيل اختبارات الوحدات والأمثلة.

## ما يتضمنه

- قراءة وفحص هندسي أولي لملفات DXF وفق معيار الطبقات الموثق في `ARCHITECTURAL_DXF_STANDARD_AR.md`.
- تكوين هندسي مرشح متعدد الأدوار من مسقط الأرضي والمتكرر وبيانات الارتفاعات والمناسيب.
- وكيل محلي يستخدم tool-calling وسجلًا لنتائج الأدوات وسياق المشروع.
- محللات خطية تجريبية لإطارات 2D/3D، ونموذج Q4 Plate/Shell محدود، وأمثلة أحمال وحالات تحميل ومراجعات هندسية تمهيدية.
- أمثلة DXF وJSON، تقارير الاختبار، وأوامر تشغيل مستقلة.

## حدود هندسية حاسمة

هذا الإصدار **ليس برنامجًا مكتملًا لتصميم مبنى خرسانة مسلحة طبقًا للكود المصري**. تكوين الـ DXF والنموذج متعدد الأدوار مرشحان ويحتاجان إلى مراجعة؛ محللات التحليل محدودة النطاق؛ ولا يوجد حتى الآن مسار مؤهل ومتحقق بالكامل لتصميم المقاومة والخدمة لجميع عناصر المبنى، أو تصميم الأساسات، أو تسليح وتفريد BBS معتمدين، أو لوحات صالحة للتنفيذ. لا تعتبر نجاح الاختبارات البرمجية أو الاتزان العددي دليلًا على سلامة المبنى.

**كل المخرجات الحالية `NOT FOR CONSTRUCTION`.** يجب مراجعتها والتحقق منها بواسطة مهندس إنشائي مؤهل قبل أي استخدام هندسي، ولا ينبغي الاعتماد عليها في التنفيذ.

## الأدلة

- `INTERFACE_GUIDE_AR.md` — استخدام الواجهة.
- `ARCHITECTURAL_DXF_STANDARD_AR.md` — معيار إعداد رسومات DXF.
- `BUILDING_STACK_GUIDE_AR.md` — تكوين الأدوار والمناسيب.
- `BUILDING_MODEL_PREFLIGHT_GUIDE_AR.md` — فحص اتصال النموذج.
- `AI_AGENT_BEHAVIOR_GUIDE_AR.md` — سلوك وكيل AI وحدوده.
- `TEST_REPORT.md` — تقرير الاختبارات الحالي وسجل الموانع.
- `CHANGELOG.md` — سجل تغييرات الإصدارات.

## التشغيل المحلي والبيانات

البرنامج مصمم للتشغيل محليًا، ولا يحتاج API مدفوعًا للتحليلات التي ينفذها محرك Python. تحتاج ميزات اللغة إلى نموذج Ollama محلي مثبت. ملفات المشروع المحلية توجد في `.structural_studio_local/`؛ احتفظ بنسخ احتياطية ولا ترفع بيانات مشاريع حقيقية أو حساسة إلى مستودع عام.
